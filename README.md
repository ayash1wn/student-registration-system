# Университет студенттерін тіркеудің ақпараттық жүйесі

## Жоба туралы

Бұл жоба университеттегі студенттер туралы ақпаратты
жинауға, сақтауға, өңдеуге және басқаруға арналған.

Жүйе студенттерді тіркеу процесін автоматтандырып,
қажетті ақпаратты жылдам табуға мүмкіндік береді.

## Жүйенің негізгі пайдаланушылары

- Студент
- Деканат қызметкері
- Жүйе әкімшісі

## Жүйенің негізгі функциялары

- Жаңа студентті тіркеу
- Студент туралы ақпаратты өзгерту
- Студенттерді іздеу
- Студенттер туралы ақпаратты қарау
- Есептерді қалыптастыру

## Қолданылатын құралдар

- Git
- GitHub
- Markdown

## Жобаның құрылымы

- README.md — жоба туралы ақпарат

- docs/use-case.md — пайдаланушылардың әрекеттері
- docs/diagrams/ — жүйе диаграммалары
