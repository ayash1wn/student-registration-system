# Пайдаланушылардың әрекеттері

## 1. Студент

- Жүйеге кіру.
- Жеке мәліметтерін қарау.
- Оқу тобын көру.
- Мамандығы туралы ақпарат алу.
- Хабарламаларды қарау.

## 2. Деканат қызметкері

- Жаңа студентті тіркеу.
- Студент туралы ақпаратты өзгерту.
- Студенттер тізімін қарау.
- Студенттерді іздеу.
- Студенттерді оқу топтарына тіркеу.
- Есептерді қалыптастыру.

## 3. Жүйе әкімшісі

- Пайдаланушылардың аккаунттарын құру.
- Пайдаланушылардың құқықтарын басқару.
- Жүйенің қауіпсіздігін бақылау.
- Деректер базасын басқару.
