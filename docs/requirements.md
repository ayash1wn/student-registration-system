# Жүйеге қойылатын талаптар

## 1. Функционалдық талаптар

1. Жүйе жаңа студентті тіркеуі керек.
2. Студент туралы ақпаратты өзгерту мүмкіндігі болуы керек.
3. Студенттерді аты-жөні бойынша іздеу мүмкіндігі болуы керек.
4. Студенттің жеке және оқу туралы ақпаратын көрсетуі керек.
5. Студенттер саны бойынша есеп қалыптастыруы керек.
6. Студенттерді оқу топтарына тіркеуі керек.

## 2. Функционалдық емес талаптар

1. Студенттердің жеке мәліметтері қорғалуы керек.
2. Жүйені пайдалану ыңғайлы болуы керек.
3. Ақпарат сенімді сақталуы керек.
4. Жүйе пайдаланушының сұраныстарына жылдам жауап беруі керек.
5. Деректердің резервтік көшірмесі жасалуы керек.

## 3. Жүйенің пайдаланушылары

- Студент
- Деканат қызметкері
- Жүйе әкімшісі
